# Task Manager API — C# / MongoDB

A small REST API built with ASP.NET Core and MongoDB.

## Project history

This repository represents an earlier stage of my backend development journey. The goal was to learn how to build a REST API, model application data and persist it in MongoDB.

Rather than replacing the original implementation with a completely different architecture, the repository is kept as a historical project and cleaned up so its purpose is clear.

## What this project demonstrates

- C# / ASP.NET Core
- REST API fundamentals
- MongoDB persistence
- Dependency Injection
- Service-oriented application structure
- CRUD-oriented business operations

## Architecture

The original project separates the API concerns from the application logic and persistence layer. This makes it useful as a snapshot of the progression from basic CRUD development toward more structured backend architecture.

## Technical note

The project currently targets an older .NET generation. It is intentionally documented as a legacy learning project rather than pretending to be a current production template.

A future modernization can upgrade the framework and dependencies after compatibility and behavior are verified.
